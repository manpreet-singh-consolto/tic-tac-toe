## 📞 Quick Support

### If you need to...

**Add a new color:**
Choose from the 9-color palette or create a new one following the sea green theme

**Update a button:**
Use the gradient: `linear-gradient(135deg, #20B2AA 0%, #2E8B8B 100%)`

**Change text color:**
Use #0a2a2a for dark backgrounds, #2E8B8B for medium, white for bright

**Create a shadow:**
Use template: `0 4px 8px rgba(0, 0, 0, 0.1), 0 6px 12px rgba(32, 178, 170, 0.3)`

**Modify a card:**
Use: `linear-gradient(135deg, #AFEEEE 0%, #B0E0E6 100%)`
